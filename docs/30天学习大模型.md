# 第一周（11.14~11.21）

## day01（11.14）

### 初步学习Git

```bash
# git 分为工作区和暂存区，只有将文件从工作区提交到了暂存区之后才能commit提交到本地仓库中


git status 
# 能清晰地告诉你哪些文件在工作区（红色），哪些文件已经进了暂存区准备提交（绿色）。
git add .
# 是全盘接收。只要你在当前目录下改了东西、或者创建了新文件，它全部都会帮你打包进暂存区
git add docs/00-start-here.md docs/01-learning-goals.md

# 这意思是把docs/00-start-here.md docs/01-learning-goals.md这两个文件提交到暂存区

git diff --cached 
# 检查一遍更改文件
# 按 q 可以退出 Git 的分页查看界面。
```
